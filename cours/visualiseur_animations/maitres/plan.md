# Plan — visualiseur d'animations du roguelike

Une case par étape ; on coche une étape quand ses tests sont verts et qu'on l'a vue tourner. On ne passe pas à la
suivante avant. Le visualiseur est une application à part : il lit les assets dans les dossiers de ses réglages
(`5_data/visualiseur/config.json`), tels que Blender et l'optimiseur d'atlas les écrivent.
