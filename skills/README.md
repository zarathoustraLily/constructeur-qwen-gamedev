# Fiches de compétences

Une fiche `SKILL.md` par compétence (C1, C2, S1, S2, S3, K1, K2, K3, K4, D1, D2, F1, F2), au format
des skills GodotPrompter (dossier `<nom>/SKILL.md`, en-tête `name` et `description`). Chaque fiche
dit quand l'utiliser, le format d'entrée et de sortie, et l'outil juge à appeler.

Elles équipent Qwen, elles ne le gouvernent pas : rien n'y impose un découpage ni un ordre de
travail (CLAUDE.md, règle 1). `outils/opencode_fusion.py` ajoute ce dossier à `skills.paths`.
